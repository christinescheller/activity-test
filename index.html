Tier Guide
When a student crosses a tier

A learning conversation first

Treat a suspected tier violation as a conversation built on evidence of understanding, not an accusation.

1

Ask them to explain the code

Pick a line or two. If they wrote it, they can walk you through it.

2

Name what the tier protected

Talk about what the tier was there for and what they missed by skipping it.

3

Close the gap

Have the student redo portions of the project if possible, or write a reflection log explaining the code.

If it becomes habitual, follow your school's academic integrity policy.
Assignment 1 of 1
Stuck? Run the three-question check
  1. Is the learning goal about AI itself (evaluating its output, testing its limits, how it works) and have students already shown the underlying skill in Red work? Both yes → Green is possible.
  2. Does the task measure or build a foundational skill where the student's own thinking is the point? Yes → start at Red. It's the default.
  3. Is there one specific, nameable AI use that comes only after an independent attempt and doesn't do the core work? Yes → a Yellow allowance may fit. Write the exact rule.
